Каталог «Теория»

Здесь собрана теоретическая база по всем блокам олимпиадного трека
по физике для 8 класса.

Что в каталоге
- По каждому блоку: ключевые понятия, законы и формулы,
  олимпиадные приёмы и типовые ошибки.
- Контент загружается в приложении в разделе «Блоки» — по кнопке
  «Теория» на карточке блока.

Уровни теории
  • База  — школьные определения и законы, нужные минимум;
  • Актив — расширенные приёмы и методы решения типовых задач;
  • Олимп — нестандартные подходы, оценки, работа с большими числами.

Мыслям разделам соответствуют папки: вы можете добавлять сюда свои
конспекты, справочники и распечатки по темам блоков.
