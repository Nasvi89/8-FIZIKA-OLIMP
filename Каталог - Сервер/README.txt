Каталог «Сервер»

Это «сервер» локального прототипа: вместо сети сервер — файл Excel
с базой данных учеников. Файл можно править в Excel и переносить между
компьютерами.

Формат файла
Файл:  База_данных_учеников.xlsx
Лист:  Ученики
Столбцы (ровно 4):
  1. ФИО
  2. ГРУППА
  3. ЛОГИН
  4. ПАРОЛЬ

Пример строк:
  Иванов Иван   | Группа 1 | ivan    | 12345
  Петров Пётр   | Группа 1 | petrov  | qwerty
  Сидорова Анна | Группа 2 | anna    | 54321

Как выгрузить базу
1. Войди как администратор (Admin / 4dm1n).
2. В панели администратора нажми «⬇ Скачать базу данных».
3. Укажи пароль администратора — скачается Excel-файл со всеми
   учениками. Положи его в этот каталог.

Как загрузить базу из Excel
1. Заполни/отредактируй Excel-файл по указанному формату.
2. В панели администратора нажми «⬆ Загрузить базу данных»,
   введи пароль админа и выбери файл.
3. Ученики и группы будут созданы (или обновлены) автоматически.

Важно
- Файл содержит реальные пароли учеников — храни его в закрытом месте.
- Импорт добавляет учеников и группы, существующие записи обновляются.
