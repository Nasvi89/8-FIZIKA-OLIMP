Каталог «Пробные олимпиады»

Здесь формируются полноформатные пробные олимпиады по физике для
8 класса — в формате, близком к реальному письменному туру ВсОШ
и олимпиады имени Д. К. Максвелла.

Что это
- Пробная олимпиада = набор из 5 задач (по 5–7 баллов каждая),
  чек-лист оформления решения «от руки».
- Ребёнок решает задачи письменно, затем сверяется с эталонными
  решениями и заполняет самооценку.
- Статистика пробных туров копится в разделе «Траектория» и влияет
  на кольца навыков «Оформление» и «Скорость решения».

Как пользоваться
1. В приложении откройте раздел «Пробная олимпиада».
2. Соберите набор задач по выбранным блокам.
3. Скачайте листы для печати (PDF / txt).
4. После работы откройте «Разбор» — эталонные решения и чек-лист.

Здесь же можно хранить скачанные копии пробных туров (pdf / txt).
