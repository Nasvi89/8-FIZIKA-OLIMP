Каталог «Траектория и достижения»

Здесь описан игровой профиль ребёнка в олимпиадном треке по физике.

РАВНЕНИЕ ПРОГРЕССА
1. Блоки. Идёте по блочной карте: блок засчитан, когда закрыты
   его задачи и «работа над ошибками».
2. Уровни. Благополучие по каждому блоку считается в процентах
   мастерства (насколько усвоена тема).
3. Навыки. Пять «колец навыков»: расчёт, оформление, эксперимент,
   скорость решения, анализ ошибок. Кольцо заполняется по задачам,
   которые ребёнок решает в ходе трека.
4. Достижения. Автоматически открываются по мере успехов
   (стрела серии, закрытые ошибки, чистый блок и т. д.).

XP И УРОВНИ
- За каждую решённую задачу начисляется опыт (XP).
- XP накапливаются — растёт уровень трека (Новичок → Физфакир и т. д.).
- Уровень открывает «бонусы скорости»: сильный ученик может прыгать
  по блочной карте и миновать уровень База.

СОХРАНЕНИЕ
- Весь прогресс хранится в браузере (localStorage) и на этом
  компьютере.
- Кнопки «Экспорт» / «Импорт» в разделе «Достижения» позволяют
  перенести прогресс на другой компьютер (облако-файл).
