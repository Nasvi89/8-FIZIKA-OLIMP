Каталог «Блоки»

Здесь описана блочная структура олимпиадного трека по физике для 8 класса.
Каждый блок — одна олимпиадная тема. Движение по блокам каскадное:
следующий блок открывается только после «зачёта» по предыдущему.

Состав программы (12 блоков):
0.  Мета: олимпиадная «техника» — эксперимент, измерения, оформление решений
1.  Кинематика: движение, скорость, равномерное и равноускоренное движение
2.  Динамика и силы: законы Ньютона, сила упругости, трения, тяжести
3.  Статика: равновесие тел, рычаги, правило моментов
4.  Гидростатика: давление, закон Паскаля, сила Архимеда, плавание тел
5.  Работа, энергия, мощность
6.  Тепловые явления: количество теплоты, тепловой баланс
7.  Тепловые машины: КПД, циклы, фазовые переходы
8.  Постоянный ток: закон Ома, сопротивление, последовательное/параллельное
9.  Электрические цепи: расчёт эквивалентных схем, правила Кирхгофа
10. Геометрическая оптика: зеркала, линзы, ход лучей
11. Финальная пробная олимпиада и работа над ошибками

Каждый блок состоит из тем (уроков) с конспектами.

У каждого блока три уровня глубины:
  • База  — школьная программа + минимум олимпиадных приёмов;
  • Актив — типовые олимпиадные задачи (школьный/муниципальный этап);
  • Олимп — задачи регионального уровня, эксперимент, нестандартные методы.

Контент блоков хранится в ../assets/data.js (метаданные и порядок),
../assets/theory.js (теория) и ../assets/bank.js (задачи).
