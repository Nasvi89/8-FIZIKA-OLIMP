Каталог «Личные кабинеты»

Здесь хранятся сохранённые личные кабинеты учеников — один файл на
ученика. Это персональный «бэкап» его прогресса: XP, пройденные блоки,
решённые задачи, навыки и достижения.

Как сохранить кабинет
1. Открой раздел «Кабинет».
2. Нажми кнопку «💾 Сохранить кабинет» — скачается файл вида
   Кабинет_Имя_логин.json
3. Положи файл в эту папку (дай имя как у ученика).

Как загрузить кабинет (на другом устройстве)
1. Открой раздел «Кабинет».
2. Нажми «📂 Загрузить кабинет» и выбери файл ученика.
   Прогресс восстановится.

Важно
- Файл кабинета содержит данные текущего залогиненного ученика.
- Пароли в файлах кабинета НЕ шифруются (локальный учебный прототип).
- Общий «серверный» файл со всеми данными и паролями находится в
  каталоге «Каталог - Сервер» и открывается только паролем администратора.
