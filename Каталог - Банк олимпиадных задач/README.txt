Каталог «Банк олимпиадных задач»

Здесь формируется банк задач олимпиадного трека по физике для 8 класса.

Задачи организованы по блокам. У каждой задачи есть:
  • блок — к какой теме трека относится;
  • уровень — База / Актив / Олимп;
  • тип — тест, расчётная, экспертная папка (на обсуждение), эксперимент;
  • решение и ответ — для самопроверки.

Решая задачи в приложении, ребёнок зарабатывает опыт (XP), закрывает
«работу над ошибками» и продвигается по блочной карте. Всё хранится
в браузере (localStorage) и переносится между устройствами через раздел
«Достижения» → «Сохранение».

Как посмотреть и добавить задачи
1. В приложении откройте раздел «Банк задач».
2. Фильтруйте по блоку, уровню и типу.
3. Нажмите «+ Добавить задачу», чтобы пополнить банк своими задачами.

Стартовый набор задач находится в файле ../assets/bank.js.
