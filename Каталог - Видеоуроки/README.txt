Каталог «Видеоуроки»

Здесь хранятся видеозаписи уроков по темам олимпиадного трека.

Как это работает
- В разделе «Блоки» открывается блок → сначала показывается
  ВИДЕОУРОК (здесь в файле lesson-video.js незамедлительно проигрывается
  ссылка или инструкция) с конспектом под ним.
- После просмотра нажимают «К задачам» → открываются задачи БЕЗ ответов.
- Видео можно класть прямо в эту папку и называть по блоку:
    Урок-1_Кинематика.mp4, Урок-2_Динамика.mp4 и т.д.
- Если видеофайл лежит в папке, приложение покажет встроенный плеер;
  иначе — покажет инструкцию и ссылку на конспект.

Конспект под видео для каждого блока находится в файле
../assets/lessons.js и автоматически выводится под плеером.
