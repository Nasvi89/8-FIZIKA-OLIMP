# Физика.Олимп — 8 класс (общая БД на Supabase)

Олимпиадная подготовка по физике для 8 класса: блоки с теорией и задачами, банк задач,
контрольные работы, классы, домашние задания, статистика учеников и учителей.

Данные хранятся **не в браузере**, а в общей базе [Supabase](https://supabase.com),
поэтому они общие для всех, кто откроет сайт: логины, пароли, классы, прогресс,
отметки по олимпиадам, домашние задания.

## Как это работает

- `db-config.js` — настройка подключения (URL проекта и публичный ключ).
- `db.js` — слой синхронизации: при открытии сайта вытягивает всю базу из Supabase
  в браузер (кэш), а каждое изменение (сохранение пользователя/класса/прогресса и т.д.)
  автоматически отправляется обратно в базу.
- Администратор по умолчанию: **логин `Nasv1`**, пароль **`16AKo1709=`** — создаётся
  автоматически при первом запуске. Не удаляйте его.

## Первый запуск (важно)

1. Откройте приложение (локально через `index.html` или на GitHub Pages).
2. Войдите как **администратор** (`Nasv1` / `16AKo1709=`).
3. При первом входе система положит админа и пустую базу в Supabase автоматически.
   Дальше добавляйте преподавателей и классы через «Кабинет».

Если база в Supabase пуста, данные появятся там после первой записи; другим
пользователям они станут видны при перезагрузке страницы.

## Выгрузка на GitHub (GitHub Desktop)

1. Скачайте и установите [GitHub Desktop](https://desktop.github.com/), войдите в аккаунт.
2. **File → New repository**: имя `8-OLIMP` (или как вам удобно), путь — любая папка.
   Создайте и остановитесь (не добавляйте файлы).
3. В проводнике скопируйте **все файлы и папки** этой папки в локальную папку репозитория
   (`...\8-OLIMP\`).
4. В GitHub Desktop появится список изменений. Внизу: **Commit to main** (сообщение,
   например «initial deploy»), затем **Publish repository** (выберите приватный или публичный).
5. Включить сайт: на сайте GitHub в репозитории **Settings → Pages → Source: main branch → Save**.
6. Сайт будет доступен по адресу: `https://<ваш-логин>.github.io/8-OLIMP/`.

Распространяйте эту ссылку среди учеников и учителей.

## Создание таблицы в Supabase (один раз)

Это уже сделано, но если создаёте новый проект:
1. [supabase.com](https://supabase.com) → ваш проект → **SQL Editor**.
2. Скопируйте содержимое файла **`supabase.sql`** и выполните его.

## Важно про безопасность

- В коде используется только **публичный ключ** (`sb_publishable_...`). Он предназначен
  для браузера.
- **Не публикуйте** в коде/файлах секретный ключ (`sb_secret_...`) и пароль базы.
- Пароли учеников хранятся в базе как есть (учебный проект). Для продакшена нужен хэш.
